## 2. 实测到的形状（**这就是我方建列与校验的唯一依据**）
两份样本各 **1 行**（一场一行，`payload` = 官方 `value` 原样、**未裁字段**），`src_hash` 复算 **两行全部一致 ✔**。
`payload` 顶层 16 键：`matchId, singleList, leagueId, leagueAbbName, leagueAllName,
homeTeamId, homeTeamAbbName, homeTeamAllName, awayTeamId, awayTeamAbbName, awayTeamAllName, hadList, hhadList, crsList, ttgList, hafuList`

| 数组（payload 里的键） | 我方 `play_type` | 元素键（实测全集） | 完场场次数 | 在售场次数 |
|---|---|---|---|---|
| `hadList` | `had` | `h,d,a` + `hf,df,af` + `goalLine` + `updateDate,updateTime` | **6 版** | 1 版 |
| `hhadList` | `hhad` | 同上，`goalLine` 形如 `"+2"` | **8 版** | 1 版 |
| `crsList` | `crs` | `goalLine` + `s-1sh/s-1sd/s-1sa` + 31 个 `sXXsYY` + 各自 `*f`（共 68 键）+ 时间 2 键 | **5 版** | 1 版 |
| `ttgList` | `ttg` | `s0…s7` + 各自 `*f` + `goalLine` + 时间 2 键 | **5 版** | 1 版 |
| `hafuList` | `haf` | `hh,hd,ha,dh,dd,da,ah,ad,aa` + 各自 `*f` + `goalLine` + 时间 2 键 | **5 版** | 1 版 |
| `singleList` | —（不落历史表） | `{poolCode, single}` | 5 | 5 |

· 合计 **34 个价格版**（7/9/6/6/6 按玩法跨两场计）；**同 `(match_id, play_type, updateDate+updateTime)` 无撞键**（实测 0 组）⇒ PK 成立；
· 数组顺序**严格"新 → 旧"**（实测单调）⇒ `seq_no = 下标`（0 = 最新一版 ≈ 封盘水）、`max(seq_no)` = 最早一版 ≈ 开盘水；
· `*f` 箭头取值实测只出现 `"1" / "0" / "-1"`（升 / 平 / 降）⇒ 原样存进 `odds` jsonb，**我方不解释成布尔**；
· 时间：`updateDate`(`2026-09-15`) + `updateTime`(`18:09:00`) = **北京墙钟** ⇒ 我方按 `AT TIME ZONE 'Asia/Shanghai'` 换算成 `timestamptz`；
· **完场场次才有完整历史**；**在售场次只有 1 版**（官方不回填开售前的历史）⇒ 想看今天某场从开盘到封盘的走势，**只能等它完场后回采一次**。
