  1) 【新】scripts/model/backtest.py     纯计算 + 写库分离，≤100 行：
       · `score_options(rows) -> dict`  给定 (p_pred, outcome) 序列，返回 `{"brier": …, "log_loss": …, "hit": …, "n": …, "eps": …}`
         - **Brier（多类）** = Σ_i (p_i − o_i)² ，o 为 one-hot；每个 (fixture, play_type) 内所有 option 都要进和（含未中奖项）
         - **log_loss** = −ln(max(p,eps))；**eps 必须是显式参数**（默认 1e-6）且**写进返回值**（p=0 是真出现的：ρ 收缩前的 1:1 格、以及 crs 里官方不开盘的档）；不许悄悄 clamp
         - `hit` = argmax(p) 是否中奖；平局/多档玩法都按"最大概率选项"判，**不许**用"命中任一非零概率"这种自欺口径
         - n=0 ⇒ 返回 `{"n":0}` 而不是崩；单选项（n_option==1）⇒ brier/log_loss 全 0 且 `degenerate: true`
       · `run(conn, src_run) -> dict`  一个 run 的回测：读 pred_market + label ⇒ 逐 (fixture,play,option) 写 `analysis.backtest_market`
         （列 `p_pred, outcome smallint 0/1, clv, src_run`），**`clv` 一律写 NULL**（无官方收盘价来源，P0-MODEL2 之后才有盘口时序；
         宁缺毋假：**绝不允许写 0.0 占位**，会被 README §2-D2 的 CLV 指标当真）。返回值给计数：`{run_id, n_rows, n_fixtures, plays:{…}, no_label:…}`
       · label 谓词**必须照抄** `store/query.py` 里的训练谓词（`r.source='api_football' AND f.status='ft' AND f.round <> 'Relegation Round'`），
         不许自己另写一套；无 label 的场 **计入 skipped 并返回计数**，不许静默丢
