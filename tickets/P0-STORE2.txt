【A. 新建 `scripts/store/parse_jbq.py`（≤100 行，函数 ≤50 行）】
 公开面（`jc_load.py` 与 `parse_collector.py` 都按这个签名调）：
```
def parse_result(env: dict) -> dict:   # 返回 {"match": {...jbq_match 一行...}, "row": {...jbq_result 一行...}}
```
 **映射表（payload 键 → 目标列；左边是官方原键，右边是 `fact.jbq_*` 真实列名，队长 07:27 从 `information_schema` 核对过）**
| payload（22 键，实测存在） | 去向 | 规则 |
|---|---|---|
| `matchId` int | `match.match_id` / `row.match_id` | 原值 |
| `matchNum` `"1301"` / `matchNumStr` `"周一301"` | `match.match_num` / `match.match_num_str` | 原文，不解析 |
| `leagueId` int / `leagueName` / `leagueNameAbbr` | `match.league_id` / `league_cn` / `league_abbr` | 原文（实测 7=女篮世界杯、8=亚运会男篮） |
| `homeTeam`/`awayTeam` | `match.home_cn` / `away_cn` | 竞彩中文全名 |
| `homeTeamId`/`awayTeamId` int | `match.home_sporttery_id` / `away_sporttery_id` | 按 id 认队；**不许**填 `home_team_id`（映射未核对） |
| `matchDate` `"2026-09-14"` | `match.match_date` | `date.fromisoformat`；**解析失败 → None**（不许猜年） |
| `matchTime` `"12:00:00"` | `match.match_time` | 原文 |
| `matchDate`+`matchTime` | `match.kickoff_bj` | 按**北京时**合成 timestamptz；**任一缺 → None** |
| `status` int / `poolStatus` str | `match.status`/`pool_status`、`row.status`/`pool_status` | 原值（实测 status 全 2、poolStatus 全空串）**不翻译** |
| `finalScore` `"61-105"` | `row.final_score` 原文 + `row.ft_h`/`ft_a` 切分 | 切不出两个整数 → 两列都 **None**，原文照存 |
| `mnl`/`hdc`/`hilo`/`wnm` 四块 | `row.mnl_combination`/`mnl_desc`/`mnl_result_status`/`mnl_odds` …（每块 4 列，`wnm` 无 line） | `combination`/`combinationDesc`/`resultStatus` **原文**；`winOdds`→`*_odds` |
| `hdc.goalLine` / `hilo.goalLine` | `row.hdc_line` / `row.hilo_line` | 真值在**块内**（实测 "-25.5"/"171.5"），**顶层没有 goalLine** |
| 四块整体 | `row.raw_blocks`（jsonb） | `{mnl,hdc,hilo,wnm}` 原样 dict（宁可不插不可插错：解析列判错可重算） |
| 任一块的 `single` | `row.betting_single` | 实测全 0 |
 **硬规则（错一条整单拒收）**：
 ① 官方原值是**空串 `""`** 的，解析列一律给 **`None`**，**绝对不许**给 `0`、`""`、或 `-1`（0 在盘口里是有意义的数据）；
 ② `resultStatus` 可能是**中文**（实测 `"未开售"`）⇒ 当字符串原文存，不判布尔；
 ③ `*_odds` / `*_line` 用 `decimal`（照 `store/parse_values.py` 的 `dec()`，它已经处理"空串/非数字 → None"）；
 ④ 不认识的键**整块留在 `raw_blocks`**，不许丢，也不许自己发明列。
