【要实现的公开面（固定，名字不许改）】
`scripts/ingest/jc_issue_write.py`：

  **必须是下面这个"表 → 允许列"的字面 dict**（队长 17:05 修正：只写表名集合会让 `jc-cols-check.py` 扫不到写点 ⇒ 它按设计 `exit 2` "这不是通过"；
   而 dict 形态既能被静态核对，又能当白名单，**一举两得**）：
  ```
  COLUMNS = {
      "fact.jc_issue": ("game_num", "issue_no", "game_name", "sale_begin", "sale_end", "draw_at",
                        "n_matches", "draw_num_list", "raw_head"),
      "fact.jc_issue_draw": ("game_num", "issue_no", "game_key", "game_name", "draw_result", "pool_after",
                             "sales", "pool_after_rj", "sales_rj", "paid_begin", "paid_end",
                             "is_delay", "delay_remark"),
      "fact.lottery_draw": ("game_num", "issue_no", "game_name", "draw_date", "status", "numbers_raw",
                            "numbers", "pool", "prizes", "equipment_count"),
  }
  ```
  ⇒ 写手第 1 步查 `COLUMNS`：**表名不在里面 ⇒ `ValueError`**；
  第 2 步**逐列过滤**：`ins["row"]` 里出现了 `COLUMNS[table]` 之外的列 ⇒ 同样 `ValueError`（**防解析器将来漂移把错列名带进 SQL**）；
  第 3 步主键两列必须在 `row` 里，否则 `ValueError`。

  def upsert_issue_instruction(cur, ins: dict, src_hash: str, src_file: str) -> int:
      """一条写指令 → 一行 UPSERT；表名/列名不在 COLUMNS 登记内 ⇒ 抛 ValueError（响亮，别静默跳过）；返回受影响行数(0/1)。"""

  实现要点（照抄级，逐条对齐）：
   1. `table = ins["table"]`；`cols_ok = COLUMNS.get(table)`；`if cols_ok is None: raise ValueError(f"未知写指令目标表 {table!r}")`；`extra = set(ins["row"]) - set(cols_ok)`；`if extra: raise ValueError(f"指令含未登记列 {sorted(extra)} → {table}")`
   2. `row = {k: (None if v == "" else v) for k, v in ins["row"].items()}`   # ① 空串归一
   3. `cols = list(row)`，再 `cols += ["src_hash", "src_file"]`；`vals = list(row.values()) + [src_hash, src_file]`
   4. 冲突目标用 `ins["pk"]` 的键**排序后**拼：`", ".join(sql.Identifier(c).as_string(None) for c in sorted(pk_cols))`（三表都是 `("game_num", "issue_no")`）
   5. SET 子句 = **所有非主键列 `c = EXCLUDED.c`**，再加 `last_seen_at = now()`；
      ⚠️ **`first_seen_at` 绝不出现在 SET 里**（首见时间只能由 DDL 默认值在真正插入那一次落定）
   6. 用 `psycopg.sql` 拼：`sql.SQL("insert into {} ({}) values ({}) on conflict ({}) do update set {}")`
      · 表名必须是 `sql.Identifier(schema, name)`（**两参拆开**，§9 铁律：`sql.Identifier("fact.jc_issue")` 会把点吃进引号 ⇒ UndefinedTable）
      · 列名逐个 `sql.Identifier(c)`；`"c = EXCLUDED.c"` 用 **`sql.SQL`** 拼（用 Identifier 会整句变成一个带引号标识符 ⇒ 语法错）
      · **验收必须**：把**整条**语句 `.as_string(None)` 渲染出来读一遍（只渲染一段会漏，§9 铁律）
   7. `cur.execute(...)` 后 `return cur.rowcount or 0`（**照 `jc_odds_write.py` 里已验收的写法**）
   8. **不要**在写手里开事务、不要 `commit()`、不要自己 catch 一切异常（连接归调用方，§9-83）
